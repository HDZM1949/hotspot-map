# 🌍 HotspotMap 世界热点地图

打开网页就是一张实时世界地图，全球的新闻、地震、灾害等热点事件自动汇聚、实时更新，无需刷新。

## 为什么需要它？

- **打开即见**：不需要安装任何东西，双击一个文件就能在浏览器里看到遍布全球的实时热点。
- **信息聚合**：把分散在新闻、地震监测、灾害报告里的信息，按地理位置落到一张世界地图上，一眼看清"现在全世界在发生什么"。
- **自动更新**：新事件发生后会自动出现在地图上，不用手动刷新。
- **筛选与探索**：可以按类型（新闻/地震/灾害）、按时间范围（今天/近三天/一周内）、按关键词搜索，看热度排行，点开每个事件查看细节。
- **自动清理**：超过一周的旧事件会自动从数据库中清除，页面始终只保留近期热点。
- **本地私有**：数据存在你自己的电脑上，完全免费、无账号、无广告。

## 主要功能

- 🗺️ **实时世界地图**：事件按地理位置显示在地图上，缩放时自动聚合/展开。
- ⚡ **实时推送**：新事件一出现就自动加到地图上（无需刷新）。
- 🎨 **分类着色**：不同事件类型用不同颜色区分。
  - 灾害（红）、冲突（橙）、政治（蓝）、经济（绿）、科技（紫）、体育（浅绿）、科学（青）、天气（黄）
- 🔍 **关键词搜索**：搜索框输入关键词（如「地震」），地图实时过滤。
- 🧷 **多源筛选**：切换只看"新闻/地震/灾害"或全部。
- 🕒 **时间筛选**：按「今天 / 近三天 / 一周内」过滤事件；超过一周的旧事件会被自动清理、不再保留。
- 🔥 **聚合 / 热力图视图**：一键切换两种呈现方式。
- 📊 **统计面板**：总事件数、24 小时新增、各分类占比、热度 TOP5。
- 📌 **事件列表**：左侧列出当前视野的高热度事件，点击自动飞到对应地点。
- 🔗 **详情弹窗**：点击地图上的点，查看事件标题、时间、类型、来源、热度。

## 安装方法

> 项目面向 Windows 桌面本地运行，仅需装好 Node.js 和 pnpm，其余（数据库、服务、计划任务）由脚本自动配置。

### 前置要求（首次一次性）

1. 安装 **Node.js 20 及以上**（推荐 LTS 版本）。
2. 安装 **pnpm**：在命令行执行
   ```
   npm install -g pnpm
   ```

### 首次安装（一条命令自动完成）

以 **管理员身份** 双击运行：

```
scripts\init.cmd
```

它会自动：授权目录 → 创建 4 个计划任务（数据库/后端/前端/自动采集）→ 安装项目依赖并构建。

> 计划任务以 Windows **内置的非管理员账户** `NT AUTHORITY\NetworkService` 运行，**不会在你电脑上新建任何账户，也无需设置密码**（这样 PostgreSQL 才能正常启动）。

> 也可手动执行安装依赖：
>
> ```
> pnpm install
> ```

完成后项目即可使用。

## 使用方法

### 每天打开：双击一个文件

双击项目根目录的：

```
run.cmd
```

它会自动启动数据库、后端、前端，检测就绪后**自动打开浏览器**，地图出现即可使用。

> 页面打不开或想随时恢复时，再双击一次这个文件即可。

### 手动启动（可选，代替双击）

```
pnpm dev         # 启动前端 + 后端（需先另开一个窗口启动数据库）
pnpm run db:start   # 启动数据库（仅本地手动配置时）
```

启动后可访问：

| 入口     | 地址                  |
| -------- | --------------------- |
| 网页     | http://localhost:5173 |
| 后端入口 | http://localhost:3000 |

### 数据采集（默认已自动，可选手动）

双击或用命令触发一次手动采集（新闻/地震/灾害三种数据源）：

```
pnpm --filter @hotspot-map/ingesters ingest:once
```

默认已有计划任务每 5–15 分钟自动采集一次，无需手动操作。

### 常用配合命令

```
node scripts\start-all.mjs     # 一键启动全部服务并输出状态
node scripts\status.mjs        # 查看服务状态与数据量
node scripts\check-services.mjs # 体检每个服务是否正常
```

## 目录说明（只需知道这几个）

```
hotspot-map\
├── run.cmd        ← 每天双击它打开网页
├── scripts\
│   ├── init.cmd   ← 可选：创建计划任务常驻模式（管理员）
│   ├── start-db.bat / start-api.bat / start-web.bat / start-ingest.bat
│   │                    ← 四个服务的启动脚本
│   └── *.mjs            ← 状态检查 / 一键启动等运维工具
├── logs\               ← 运行日志（服务出错时查看）
├── apps\web            ← 网页（地图）
├── apps\api            ← 后端
├── packages\           ← 采集器 / 数据处理 / 共享代码
└── infra\              ← 数据库初始化脚本
```

## 常见问题

**点了“run”但网页打不开？**
再双击一次即可（脚本会自动重启服务）。仍不行就先重启电脑再试，或查看 `logs\` 目录下的日志文件。

**首次运行提示找不到任务或需要管理员？**
一键启动会直接以进程方式启动服务，不需要管理员。仅当你选择“计划任务常驻模式”时，才需要以管理员运行一次 `scripts\init.cmd`。

**数据是空的 / 没有实时更新？**
启动后会自动开始采集。若长时间无数据，可能网络受限（如 HTTPS 被拦截），可设置环境变量 `INGEST_TLS_BYPASS=1` 后重启采集；或手动执行一次采集命令。
